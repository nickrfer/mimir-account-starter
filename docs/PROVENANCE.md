# Procedência da base técnica

Scaffold preparado em 31/10/2026 a partir de especificação própria e contratos harmonizados do Mimir-Account. Foram selecionadas regras técnicas, diagramas próprios e dados sintéticos. Não foram incluídos normas institucionais, relatório acadêmico, conversas, contexto pessoal ou código do projeto pessoal anterior.

OpenAPI, JSON Schemas, vetores de fingerprint e totalização foram copiados sem alterar seus bytes do conjunto documental vigente. Os exemplos também foram preservados byte a byte, exceto textos LEIA_ME de navegação, adaptados à estrutura do repositório. Os manifestos, referências externas e arquivos declarados nos manifestos mantêm os bytes conferidos.

Esta procedência não comprova software construído. O status correto está em STATUS.md. A licença MIT deste repositório não substitui as licenças de dependências futuras, que precisam ser registradas ao adicioná-las.
